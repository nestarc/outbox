## Goal

Implement the remaining v0.2.0 specification after broker-capable transport mode:

- stable event metadata/envelope;
- tenant propagation;
- local handler context;
- admin and DLQ operations;
- observability hooks;
- optional PostgreSQL LISTEN/NOTIFY wakeup;
- migration SQL, docs, and verification.

## Constraints

- Preserve v0.1 local handler compatibility where practical.
- Keep broker mode changes already implemented.
- Prefer additive public API changes.
- Use TDD for each behavior before production edits.
- Avoid hard dependency growth unless the feature cannot work without it.
